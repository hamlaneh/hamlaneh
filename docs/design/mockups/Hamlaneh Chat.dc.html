Desktop rows are 36 px tall because the pointer is precise and density matters in a list read all day; on mobile every row and control goes to 44 px. Both clear the 40 px product floor for touch, since the 36 px desktop row is pointer-only.
02 · message
Bubble anatomy and grouping
Others' messages sit on the logical start side in surface with a border.subtle outline; your own sit on the logical end side in brand.soft with no outline. The first bubble of a run notches its leading top corner to 4 px; the rest stay at 12 px. Side is set by align-items on a column flex, so RTL mirrors with no extra rules.

05 · behaviour
Interaction, accessibility, bidi, responsive
Messaging
Enter sends, Shift+Enter opens a line. The hint row states this permanently rather than teaching it once.
A sent message appears immediately as your own bubble; failure to reach the server converts it to the dashed queued treatment rather than dropping it.
Consecutive messages from one author within five minutes group under a single avatar, name and timestamp.
The unread divider is placed on entry and stays until you leave the channel — it does not jump as new messages arrive.
Editing replaces the bubble with an inline composer; the message keeps its position.
Deleting leaves a dashed placeholder so the conversation does not silently reshape.
Accessibility
The message list is a labelled log region; new arrivals announce politely, never assertively.
Connection changes announce through role="status"; nothing steals focus from the composer.
Hover actions are reachable by keyboard: focus inside a message reveals the same toolbar.
Bubble fill is never the only carrier of authorship — the name row and the side both say it, and both survive high-contrast mode.
Every avatar has a text name beside or behind it; presence dots pair with words.
Desktop rows are 36 px pointer targets; every touch target is 44 px.
Bidi
Bubble side comes from align-items on a column flex, so the whole conversation mirrors from the dir attribute alone.
Corner notches use border-start-start-radius / -start-end-radius, never top-left or top-right.
Channel slugs, filenames, version tags and URLs are isolated LTR runs inside Persian text.
Message bodies are dir="auto" — a Persian message in an English workspace still reads correctly.
Only directional glyphs mirror: send, reply and back. Attach, search, download and the hash do not.
Persian sets at 1.7–1.75 line-height with no negative tracking.

Reused from the auth set without change
Every colour, type step, spacing value, radius, focus ring, disabled treatment and motion duration. The dashed-boundary disabled convention carries over from the login fields to the disconnected composer. Banner anatomy — icon plus text, tinted fill, 1 px matching border — is the same component as the login notices, with warning and success reused for connection state.
