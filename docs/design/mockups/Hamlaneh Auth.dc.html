09 · behaviour
Interaction, accessibility, responsive
Forms
Enter submits the active form.
Validate on blur and again on submit — never on every keystroke.
Submission disables the control and blocks duplicate requests; the label swaps to the stable busy string.
After an invalid submission focus moves to the first invalid field, or to the alert when the failure is form-level.
The identifier survives a failed sign-in; the password field clears.
Credential errors are announced through role="alert"; the reset confirmation through role="status", which does not steal focus.
Autocomplete: identifier username · sign-in password current-password · new passwords new-password · reset email email · code one-time-code.
Accessibility
Normal text ≥ 4.5:1, large text and control boundaries ≥ 3:1, both themes verified separately.
Visible labels always present, including on filled fields; placeholders are examples, never labels.
Every target is at least 44 × 44 px — above the 40 px product floor.
Tab order equals visual reading order in LTR and RTL alike; the RTL DOM order is the RTL reading order.
Icon-only controls carry accessible names and tooltips; the password toggle's name flips between Show and Hide while keeping focus.
Error, warning, success, selected and disabled are all carried by glyph, weight or border style as well as colour.
Survives 200% zoom and text scaling: the column reflows, the page scrolls, no control shrinks below its accessible size, no focus ring is clipped.
Language switching stays available before authentication and never uses flags.

Bidi rules
Email addresses, URLs and one-time codes are isolated LTR runs inside the RTL page; the identifier field is dir="auto" because it accepts either. Latin characters, digits and punctuation are never reversed. The OTP row keeps dir="ltr" so the first digit typed is always the leftmost cell. Only arrow-left mirrors; eye, eye-off, alert, check and info do not.

Every state on this canvas is a variant of these thirteen — no detached one-offs. Token names map straight to CSS variables and Tailwind 4 @theme keys.
Fonts — self-hosted, no CDN
Inter — rsms/inter, SIL Open Font License 1.1. Ship InterVariable.woff2 (weight axis 100–900) plus the static 400/500/600 as fallback; subset to latin + latin-ext.
Vazirmatn — rastikerdar/vazirmatn, SIL Open Font License 1.1. Ship Vazirmatn[wght].woff2 plus static 400/500/600; keep arabic + Persian digits in the subset.
Both live in webapp/public/fonts/, declared with @font-face and font-display:swap. Weight mapping: body 400, labels and links 500, headings and buttons 600, 700 unused in this scope.
Fallback stack: system-ui, -apple-system, "Segoe UI", sans-serif. The canvas above renders from web fonts for review only.
Icons
Lucide, ISC license. Ten glyphs in this scope: eye, eye-off, circle-alert, triangle-alert, circle-check, circle, info, arrow-left, check, loader-circle (plus moon for the theme control if a theme toggle ships here later).
Inline SVG only — no icon font, no sprite fetch. If lucide-react is not taken as a dependency, the paths as drawn on this sheet are the source of truth; they are plain stroke paths on a 24 × 24 viewBox at 1.75 stroke width, currentColor, round caps and joins.
Pin one exact version in package.json and record it here when the dependency lands; the drawn paths track Lucide 0.4x.
Decorative art — the nested-arc motif — is an editable inline SVG, aria-hidden, and removable: delete it and the panel still reads as finished.
